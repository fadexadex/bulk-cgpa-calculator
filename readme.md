# CGPA Calculator

A sleek, minimalist black and white frontend application for calculating and visualizing student CGPA data.

## Overview

This application provides a modern interface for uploading student grade data in CSV format, calculating CGPA values, and displaying the results in an intuitive and visually appealing manner. The system processes course grades and units to compute Cumulative Grade Point Averages (CGPA) for each student and presents the data in both tabular and card formats.

## Features

- **File Upload**: Drag-and-drop interface for uploading CSV files
- **Data Processing**: Backend integration for CGPA calculation
- **Dual View Options**:
  - Grid view (cards) for visual presentation
  - List view (table) for detailed data analysis
- **Search & Sort**: Find and organize student records easily
- **Analytics Dashboard**: View average CGPA and performance metrics
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Download Results**: Export processed data as CSV

## Installation

### Clone the repository:
```bash
git clone https://github.com/yourusername/cgpa-calculator.git
cd cgpa-calculator
```

### Backend Setup
```bash
cd backend
npm install
npm run start
```

### Frontend Setup
```bash
npm install --force
npm run dev
```

## Usage
1. Start the backend and frontend servers.
2. Open the frontend app in your browser.
3. Upload a properly formatted CSV file with student grades and course units.
4. View results in grid or list format.
5. Search, sort, and analyze student performance.
6. Download processed data as CSV if needed.
